## 🚀 Featured Projects

### 🧠 SynaptIQ — AI-Powered Cognitive Workspace

A Generative AI workspace designed for intelligent document retrieval, contextual question answering, and multi-step AI workflows.

**Key Engineering Work**

- Developed backend APIs using Python and FastAPI
- Implemented Retrieval-Augmented Generation (RAG)
- Used Gemini 768-dimensional embeddings for semantic retrieval
- Integrated PostgreSQL and PGVector for vector storage
- Designed hybrid rule-based and LLM-assisted request classification
- Developed LangGraph workflows with Planner, Worker, Auditor, and Synthesizer nodes
- Integrated Supabase JWT authentication and Row Level Security

**Tech:** Python, FastAPI, RAG, LangGraph, Gemini, PostgreSQL, PGVector, Supabase

---

### 🏃 XCETRA — Event Registration & Booking Platform

A production-deployed platform connecting running clubs and event participants across multiple countries.

**Key Engineering Work**

- Developed REST APIs using Python, Django, and DRF
- Built event registration, booking, and user management workflows
- Integrated Razorpay for online payment collection
- Implemented Redis-based OTP authentication
- Developed SMTP-based email notification workflows
- Built frontend interfaces with Next.js and React
- Deployed backend services on AWS EC2 and frontend on AWS Amplify
- Managed production deployments, Git-based updates, and SSL configuration

**Tech:** Python, Django REST Framework, Next.js, React, PostgreSQL, Redis, Razorpay, AWS EC2, AWS Amplify
